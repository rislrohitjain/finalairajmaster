What is the Use of this Project? / उपयोग

Rajasthan Administrative & Geographic Master Portal (RajMaster AI)

🎯 Engineering Showcase & Learning Architecture

RajMaster AI is a full-stack educational and engineering portfolio showcase developed to demonstrate advanced mastery in Generative AI, LangGraph Multi-Agent Orchestration, Multi-Cloud LLM Failovers (Gemini 2.5 Flash, Groq Llama-3.3-70b, Ollama), Python FastAPI, PostgreSQL Vector RAG, and modern Angular 19 SPA for top-tier AI engineering opportunities in today's trending tech marketplace.

Instead of generic web searches, this architecture showcases how an intelligent LLM agent interacts with normalized hierarchical relational data (10 Divisions, 50 Districts, Tehsils, Gram Panchayats, Urban Local Bodies, and Pincodes) to deliver structured, deterministic, and instant answers with sub-second latency.

⚠️ Portfolio Disclaimer: This project is a simulated technical demonstration built for learning, research, and portfolio presentation. It is not affiliated with or endorsed by any government entity, and all administrative data is simulated for demonstration purposes.

1 Step 1: User Text Input & Language Detection 📱

The citizen or revenue officer types an administrative question in English, Hindi, or Hinglish (e.g., "What is the division of Balotra?" or "Show database stats via MCP"). The frontend captures this and dispatches a JSON POST payload to /api/chat/stream.

2 Step 2: Guardrail Classifier & Intent Parsing 🛡️

Before running database or AI queries, the guardrail_classifier_node evaluates the query:

  • Geographic / MCP Query: Contains district, tehsil, village, 6-digit pincode, or MCP database inspection ➔ Routes to LangGraph + MCP.
  • Capability Query: Asks for help, overview, or 6 tiers ➔ Routes to Capability Node.
  • Out of Scope: Non-Rajasthan general queries ➔ Routed to official scope notice with citizen helpline 89988555525.

3 Step 3: LangGraph 6-Tier PostgreSQL + MCP Server (JSON-RPC 2.0) ⚡

The agent performs high-precision matching across PostgreSQL AND invokes the local/live finalairajmaster-postgres-mcp server over JSON-RPC 2.0 (stdio-jsonrpc locally / inprocess-jsonrpc fallback in serverless) using 5 MCP tools: get_administrative_lineage, get_database_stats, list_tables, describe_table, and read_query.

1. State: Rajasthan
2. 10 Divisions
3. 50 Districts
4. Sub-Divisions (SDM)
5. Tehsils & Blocks
6. Villages & Pincodes

Offline Resilience: If PostgreSQL has network latency, the built-in _lookup_in_memory_master resolves all 50 districts, divisions, and postal prefix ranges instantly.

4 Step 4: If Not Found — RAG & Live Web Search Fallback 🔎

If direct 6-tier PostgreSQL & MCP lookup finds no match, synthesizer_node automatically triggers a multi-stage fallback:

  • Database RAG Retrieval: Fuzzy SQL search across raj_masters.pincodes, tehsils, blocks, and districts.
  • Live Web Search: Real-time lookup via DuckDuckGo / Tavily / SerpAPI / Wikipedia if RAG also misses.
  • Helpline Notice: Clean fallback notice with citizen support helpline if still unmatched.

5 Step 5: Cloud LLM Grounding & Zero-Hallucination Synthesis 🤖

Verified records from PostgreSQL/MCP and RAG are synthesized deterministically (or via Cloud LLM APIs: Google Gemini, Groq, Hugging Face, OpenAI, or local Ollama) strictly grounded in official data, ensuring zero hallucination.

6 Step 6: Final Output, MCP Badges & Next Questions 💬

The user receives:

1 Step 1: Audio Capture & Acoustic Waveform Monitoring 🎙️

When the citizen clicks Jain Live Voice, the browser requests microphone permission via the HTML5 navigator.mediaDevices.getUserMedia. An active Web Audio AudioContext monitors real-time sound decibels and drives the pulsating neon waveform visualizer on screen.

2 Step 2: Real-Time Speech-to-Text (STT) Recognition 📝

The webkitSpeechRecognition / SpeechRecognition service converts continuous vocal input into structured text tokens in real time:

  • Hindi Recognition: Calibrated for hi-IN language accent and Rajasthani phonetics.
  • English Recognition: Calibrated for en-IN (Indian English) pronunciation.
  • Auto-End Detection: Automatically pauses when the user stops talking for 1.2 seconds.

3 Step 3: Administrative Hierarchy & Lineage Resolution ⚡

The transcribed spoken sentence (e.g. "Tell me which division Balotra is in") is sent to the backend. LangGraph parses the entity Balotra, traverses the 6-tier administrative hierarchy, and retrieves its Division (Jodhpur Division) and District Collectorate records.

4 Step 4: Spoken Audio Text Optimization (Acoustic Cleanup) 🤖

Text formatted with markdown tables or asterisks (**) sounds unnatural when read aloud. The voice pipeline dynamically cleans the response:

🚫 Raw text: "**Balotra** is under *Jodhpur Division*..."
✅ Spoken audio: "Balotra is an officially recognized District functioning under Jodhpur Division."

5 Step 5: Text-to-Speech (TTS) Synthesis & Hands-Free Conversation 🔊

The synthesized text is spoken aloud using high-quality Indian voices (Google हिन्दी or Microsoft Heera). Once speaking finishes, the microphone automatically resumes listening, creating an effortless, continuous, hands-free conversational loop!

1 चरण 1: आवाज़ ग्रहण व माइक्रोफोन वेवफॉर्म 🎙️

ब्राउज़र का स्पीच-टू-टेक्स्ट इंजन उपयोगकर्ता द्वारा बोले गए शब्दों (जैसे: "सांगानेर तहसील किस जिले में है?") को तुरंत शुद्ध हिंदी टेक्स्ट में बदल देता है।

4 चरण 4: बोलने योग्य सहज वाक्य निर्माण (Acoustic Formatting) 🤖
